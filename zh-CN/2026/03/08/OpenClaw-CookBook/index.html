了解 OpenClaw

什么是 OpenClaw？

OpenClaw 是一个开源、自托管的 AI Agent 系统，将 AI 从”聊天工具”转变为”能够自主执行任务的数字员工”。

维度 ChatGPT OpenClaw
定位 问答顾问 数字员工
部署 云端 SaaS 本地自托管
交互 网页聊天 20+ 聊天渠道
能力 回答问题 执行任务
数据 云端存储 本地掌控

核心能力

  • ✅ 多渠道连接：Telegram、WhatsApp、飞书、钉钉、Discord 等
  • ✅ 持久记忆：记住你的偏好、项目、联系人
  • ✅ 技能扩展：通过技能系统无限扩展能力
  • ✅ 主动工作：定时任务、心跳检查、自动提醒
  • ✅ 本地数据：所有数据存储在你的设备上
  • ✅ 多 Agent 协作：为不同任务配置专用 Agent

多 Agent 配置

什么是多 Agent？

OpenClaw 支持运行多个独立的 Agent 实例，每个 Agent 可以：

  • 使用不同的模型配置
  • 拥有独立的工作空间和记忆
  • 专注于特定类型的任务
  • 独立配置技能和工具

内置 Agent 类型

Agent 用途 推荐模型
main 主对话 Agent，处理日常任务 qwen3.5-plus
chat 纯聊天 Agent，闲聊对话 qwen3.5-plus
coding 编程 Agent，代码生成/审查 Claude Opus 4.6
analysis 数据分析 Agent qwen3.5-plus

多 Agent 最佳实践

✅ 推荐：

  • 为高频任务创建专用 Agent
  • 编程时使用独立 Agent（避免上下文污染）
  • 为不同项目创建独立的 Agent 实例
  • 定期清理不活跃的 Agent

❌ 避免：

  • 创建过多 Agent（建议 ≤5 个）
  • 所有 Agent 使用同一模型（浪费资源）
  • 忽略 Agent 之间的记忆隔离

技能系统

什么是技能？

技能是 OpenClaw 的插件系统，使 AI 能够：

  • 访问外部 API（天气、新闻、股票）
  • 操作本地资源（文件、摄像头）
  • 执行特定任务（GitHub、日历、邮件）

安装技能

热门技能

技能 功能 安装命令
weather 天气预报 openclaw skills install weather
github GitHub 操作 openclaw skills install github
news-aggregator 新闻聚合 npx skills add https://github.com/BODYsuperman/world-news-aggregator-skill
pinchtab-browser 浏览器自动化 openclaw skills install pinchtab-browser
