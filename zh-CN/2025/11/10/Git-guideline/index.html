分支与合并

分支让你可以安全地进行各种尝试。

推荐的分支命名

  • main – 稳定的生产分支
  • feature/* – 新功能
  • hotfix/* – 紧急修复

常见陷阱及避免方法

  • 忘记执行 git add
  • 忽略合并冲突
  • 执行 git reset –hard 后惊慌失措
  • 使用密码而不是令牌（Token）/SSH

提示：如果出了问题，先停下来查看 git reflog。

总结

你不需要记住所有的 Git 命令。

Git 的核心不在于命令——而在于理解历史与协作。

一旦你理解了工作流，Git 就会成为一个强大的安全网，而不是焦虑的来源。
